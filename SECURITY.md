# Security Policy

## Overview

CyberSentinel is a cybersecurity assessment and security analysis project designed for authorized testing, defensive research, and security education.

Security issues affecting CyberSentinel itself should be reported responsibly rather than publicly disclosed before they can be investigated.

## Supported Versions

| Version        | Supported |
| -------------- | --------- |
| Latest         | Yes       |
| Older versions | No        |

Security fixes will generally be applied to the latest version of the project.

## Reporting a Vulnerability

If you discover a security vulnerability in CyberSentinel, please report it privately.

Please include:

* A clear description of the vulnerability
* The affected component or file
* Steps required to reproduce the issue
* Potential security impact
* Any relevant logs, screenshots, or proof-of-concept information

Please do not publicly disclose the vulnerability through GitHub Issues, pull requests, or other public channels before it has been reviewed.

## Responsible Disclosure

We encourage responsible disclosure and will make reasonable efforts to investigate reported vulnerabilities and address confirmed security issues.

Please allow reasonable time for investigation and remediation before publicly disclosing a vulnerability.

## Security and Privacy

CyberSentinel may interact with network services and collect technical information during authorized security assessments.

Users are responsible for ensuring that they have appropriate authorization before scanning or analyzing systems.

Do not use CyberSentinel against systems, networks, applications, or infrastructure that you do not own or have explicit permission to assess.

## Sensitive Information

Do not include passwords, API keys, private keys, authentication tokens, personal information, or other sensitive data in public GitHub issues or pull requests.

If sensitive information is accidentally committed to the repository, simply deleting it in a later commit does not remove it from Git history. Rotate or revoke exposed credentials immediately and then take appropriate steps to remove the sensitive data from the repository history.

## Scope

This security policy applies to vulnerabilities in the CyberSentinel project itself.

Findings discovered by using CyberSentinel against third-party systems are outside the scope of this repository's vulnerability reporting process. Such findings should be handled according to the policies and authorization requirements of the affected organization.
